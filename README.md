# VehicleDashboardApplication

Build and Run Instructions
Clone this repository on a Mac with Xcode installed.
Open the project in Xcode.
Select an available iOS Simulator.
Build and run the application using Product → Run or:
Command + R
The application should launch in the selected iOS Simulator.

Assumptions
The application is intended to demonstrate the vehicle dashboard functionality rather than a production-ready backend.
The provided vehicle data is sample/mock data.
A live backend/API is not required for the current demonstration.
The application is intended to be run using Xcode on macOS with an iOS Simulator or compatible iOS device.
The current implementation assumes that the provided JSON data is available as an application resource.

Known Limitations
The current application uses mock vehicle data rather than a production backend.
Live vehicle data integration is not currently connected to a real backend.
Authentication and user account functionality are not implemented.
Real-time vehicle tracking/data updates are not implemented.
Network error handling is limited because the primary demonstration uses local mock data.
The application may require additional testing and UI refinement across different iOS device sizes.

This repository contains the complete source code for the Vehicle Dashboard Application.
